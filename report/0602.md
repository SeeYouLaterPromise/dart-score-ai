| 指标                 | 解释              |
|--------------------|-----------------|
| **Precision（查准率）** | 预测为目标的中有多少是真的目标 |
| **Recall（查全率）**    | 实际存在的目标中你找到了多少  |
Recall 高于 Precision：说明模型比较“激进”，宁可多预测一些框，也容易出现误报（假阳性）。


第一次训练接结果：
| 类别      | Precision            | Recall        | mAP\@0.5 | mAP\@0.5:0.95 | 备注 |
| ------- | -------------------- | ------------- | -------- | ------------- | -- |
| 0、4、6、7 | 预测为 0，Recall 也为 0    | ❌ 模型没学会这些类    |          |               |    |
| 1、2、3   | Precision 高，Recall 高 | ✅ 模型学得不错      |          |               |    |
| 5       | Precision 低，Recall 高 | ⚠️ 易误报，可能数据偏少 |          |               |    |
